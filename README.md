# Iranian YouTubers Hub | دایرکتوری و جامعه یوتیوبرهای ایرانی

پایگاه داده آزاد و پرتال دایرکتوری تولیدکنندگان محتوا و یوتیوبرهای ایرانی به صورت دسته‌بندی شده و متن‌باز.

## ویژگی‌ها
- دسته‌بندی تخصصی کانال‌ها (گیمینگ، تکنولوژی، سرگرمی، پادکست، علم و مستند، اقتصاد و ولاگ)
- رابط کاربری مدرن با دارک‌مود، فونت وزیرمتن و طراحی واکنش‌گرا
- جست‌وجوی زنده، فیلتر دسته‌بندی، تگ‌ها و مرتب‌سازی بر اساس سابسکرایبر
- آواتارهای برداری محلی (SVG) بدون وابستگی به شبکه و بدون قطعی تصویر
- ساختار کاملا استاتیک و بدون هزینه هاستینگ روی گیت‌هاب پیجز (GitHub Pages)

## ساختار مخزن
```
iranian-youtubers/
├── index.html          # صفحه اصلی دایرکتوری
├── build_data.py       # اسکریپت ساخت پایگاه داده و آواتارها
├── data/
│   └── youtubers.json  # دیتابیس کانال‌ها، آمار و اطلاعات
└── avatars/            # فایل‌های آواتار برداری SVG
```

## نحوه مشارکت
برای اضافه کردن کانال جدید یا به‌روزرسانی آمار:
1. یک ایشو در مخزن باز کنید یا در فایل `data/youtubers.json` کانال مورد نظر را ثبت کرده و پول ریکوئست (PR) ارسال فرمایید.
2. فیلدهای الزامی: نام، آیدی (هندل یوتیوب)، لینک کانال، دسته‌بندی، بیوگرافی و تخمین سابسکرایبر.
